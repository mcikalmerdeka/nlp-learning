# DeepEval Experimentations

This is a repository for experimenting with the DeepEval library. The main file is `test_main.py` which contains the code for the experiments.

Important thing to remember is that when creating the test file it should use the prefix `test_` for the file names.

Another thing to remember is that most of the evaluation from this Library are actually using the "LLM-as-judge" approach.

Resources:

- [Github Repository](https://github.com/confident-ai/deepeval)
- [Official Documentation](https://deepeval.com/docs/getting-started)
